# 拼图拼接特效视频

将特效视频放在本目录，推荐文件名：

| 文件 | 用途 |
|------|------|
| `merge.mp4` | 拼接特效视频（H.264 标准 MP4，勿用 QuickTime 导出） |
| `merge_fx.png` | 视频无法播放时的备用静态特效图（可选，已内置缩略图） |

代码引用路径：`/videos/merge.mp4`（与 `/audio/move.mp3`、`/images/photo1.jpg` 同级）。

## 格式建议

- 编码：**H.264** + AAC（微信小程序兼容性最好；不要用 QuickTime 导出的「伪 mp4」）
- 容器：标准 MP4（ISO 14496-14）
- 可用 ffmpeg 转码：`ffmpeg -i 源.mp4 -c:v libx264 -c:a aac merge.mp4`
- 尺寸：可与单格或组合块外接矩形接近；透明底需 H.264 通常不支持，可用较小画幅叠在组合块中心
- 体积：建议 **≤ 2MB**，过长会影响首包与加载

## 播放时机

落位成功后，若本次移动使某连通组块数**变大**（例如 1+1→2、2+1→3），在该组合块外接矩形区域播放一次，播完自动隐藏。
