# 音效资源

路径与代码引用一致，放在小游戏根目录 `audio/` 下（与 `images/`、`js/` 同级）。

| 文件 | 用途 | 代码音量 `volume`（0~1） |
|------|------|------------------------|
| `click.mp3` | 通用按钮 | 0.65 |
| `move.mp3` | 拼图移动 | 1（引擎内未单独设，默认满幅） |
| `swap.mp3` | 拼图交换 | 1 |
| `intro_deal.mp3` | 开局发牌 | 0.75 |
| `intro_flip.mp3` | 开局翻面 | 0.75 |
| **`win.mp3`** | **关卡通关** | **0.85** |
| **`timeup.mp3`** | **倒计时归零** | **0.8** |
| `bgm.mp3` | 背景音乐（`js/bgm.js`） | 1 |

## 时间耗尽 `timeup.mp3`

- 触发：`puzzle-screen` 倒计时首次归零时 `sfx.playTimeup()`。
- 素材峰值建议 **-8～-6 dBFS**；运行时 `VOLUME.timeup` 当前 **0.8**。

## 通关音效 `win.mp3` 建议

- **格式**：mp3，时长约 **0.5～1.5 秒**。
- **运行时**：`VOLUME.win` 当前 **0.85**。

通关时在 `puzzle-screen` 的 `onWin` 中调用 `sfx.playWin()`，受设置里「音效」开关控制。
