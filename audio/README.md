# 音效资源

路径与代码引用一致，放在小游戏根目录 `audio/` 下（与 `images/`、`js/` 同级）。

| 文件 | 用途 | 代码音量 `volume`（0~1） |
|------|------|------------------------|
| `click.mp3` | 通用按钮 | 0.65 |
| `move.mp3` | 拼图移动 | 1（引擎内未单独设，默认满幅） |
| `swap.mp3` | 拼图交换 | 1 |
| `intro_deal.mp3` | 开局发牌 | 0.75 |
| `intro_flip.mp3` | 开局翻面 | 0.75 |
| **`win.mp3`** | **关卡通关** | **0.85** |
| `bgm.mp3` | 背景音乐（`js/bgm.js`） | 1 |

## 通关音效 `win.mp3` 建议

- **格式**：mp3，单声道或立体声均可，时长约 **0.5～1.5 秒**。
- **电平（素材）**：导出前峰值约 **-6 dBFS**，避免与 BGM 叠在一起爆音；响度可比 `click` 略大、比 BGM 短促突出即可。
- **运行时**：微信不支持按「分贝」设置，只在 `js/sfx.js` 的 `VOLUME.win` 用 **0～1** 线性音量；当前 **0.85**。觉得太响可改为 `0.75`，太轻可改为 `0.92`。

通关时在 `puzzle-screen` 的 `onWin` 中调用 `sfx.playWin()`，受设置里「音效」开关控制。
