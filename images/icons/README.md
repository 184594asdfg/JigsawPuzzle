# 首页底部按钮图标

请把三张图标放在本目录（`images/icons/`）：

| 功能 | 文件名 | 对应按钮 |
|------|--------|----------|
| 排行 | `rank.png` | 左侧 |
| 关卡（开始游戏） | `level.png` | 中间 |
| 图集 | `gallery.png` | 右侧 |

- 格式：PNG 透明底（也可用 `.jpg`，需在 `pages/index/index.js` 修改路径）
- 建议尺寸：侧边约 **108×108 px**，中间「开始」约 **160×160 px**（@2x 可翻倍）
