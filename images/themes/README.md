# 图集主题卡片

请在本目录放置两张卡片底图：

| 文件 | 用途 |
|------|------|
| `theme-unlocked.png` | 已解锁主题 |
| `theme-locked.png` | 未解锁主题 |
| `level-placeholder.png` | 主题详情里**未完成**关卡的缩略占位图 |

**主题卡片尺寸：240×337 像素**（宽×高）。界面一行三个、占满屏宽后按列宽等比缩放，比例已对齐。

**关卡占位图**：建议与拼图缩略图同比例 **2:3**（如 840×1260 或按比例缩小），一行三个格子内 `aspectFill` 显示。

建议使用 PNG。若用 JPG，需在 `utils/gallery-data.js` 中修改路径。

**解锁规则**：默认第一个主题解锁；通关上一主题全部关卡后，解锁下一主题。
