# 拼图尺寸与样式规范

## 布局

| 项 | 值 |
|----|-----|
| 原图 | 840 × 1260（2:3） |
| 难度 | 3×3～7×7（首页可选，默认 4×4） |
| 棋盘外宽 | 屏宽 **100%** |
| 棋盘内边距 | **12px** |
| 块间距 | **4px**（等同 grid-gap） |

```
cellW = floor((外宽 - 24 - (N-1)×4) / N)
cellH = floor(cellW × 3 ÷ 2)
step  = cell + 4
```

## 单块样式

| 属性 | 值 |
|------|-----|
| 背景 | `#ffffff` |
| 圆角 | `4px`（内层图 `2px`） |
| 内边距 | `1px` |
| 边框 | `1px solid #000` |
| 图片 | `aspectFill`，内层裁切窗口 100% 填满 |

图片偏移按内层格 `imageTileW × imageTileH`（扣除 border+padding）计算。
